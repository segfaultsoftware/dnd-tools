# Project guidance

All product work must meet WCAG 2.2 AA. Use semantic HTML and provide complete
keyboard access, visible focus states, accessible labels, and sufficient color
contrast. Interfaces must support responsive reflow across supported viewport
sizes without loss of content or functionality.

## Changelog

For every commit, add one bullet to `CHANGELOG.md` with a brief one- or
two-sentence description of the change, even for complex work. Place it under
`## Unreleased` in the appropriate `### Added`, `### Removed`, `### Fixed`, or
`### Changed` subsection. Create either heading if it does not already exist,
and preserve all existing entries.
